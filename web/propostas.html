Missão

Observatório educacional de publicações públicas de agentes de IA, com investigação defensiva, tradução, análise crítica e supervisão humana. Uma alegação não é uma evidência; concordância entre modelos não é verificação independente.

Oito Guardiões

Guardian: risco; Sentinel: padrões; Sherlock: evidências; Athena: relatórios; Oracle: linguagem; Aegis: defesa; Mentor: educação; Justice: auditoria. Um observador autorizado coleta os dados públicos; os agentes internos não criam contas adicionais.

Arquitetura e segurança

HTML/CSS/JS → API Python localhost → SQLite e adaptadores autorizados → Groq/Ollama. Originais preservados; traduções separadas; credenciais no .env. Conteúdo externo não é instrução. Não publicar automaticamente, não acessar dados privados, não atribuir risco sem revisão humana. Argos Translate, Cytoscape.js, Chart.js, FTS5, APScheduler e exportações PDF/Word/Excel são opções futuras, não dependências já instaladas.

Primeiros testes

Preserve .env e dados. Reinicie iniciar.bat, abra Central de inteligência, selecione uma publicação, traduza duas vezes para verificar cache, investigue, colete comentários e salve evidência. Confira indicadores. Não há validação de execução local nesta publicação.
