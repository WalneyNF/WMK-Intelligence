WMK Neural Memory — Manual

O banco dados/wmk.sqlite3 preserva as publicações originais. A tabela knowledge_memory guarda categorias, termos, versão do classificador e data de indexação. knowledge_fts é um índice textual FTS5, com ranking BM25. Se FTS5 não estiver disponível, a pesquisa usa LIKE.

Uso

Reinicie o servidor. Um trabalhador local indexa lotes de até 100 publicações antigas e novas, sem IA. Abra memory.html e acompanhe a cobertura. Pesquise palavras do texto original ou categorias. A pesquisa não traduz nem compreende sinônimos automaticamente.

Preservação

Faça backup do SQLite com o servidor parado. Não publique a base nem o .env no GitHub. Respeite as condições das fontes e a privacidade. O conteúdo externo é dado não confiável, não instrução para agentes.

Próximas etapas

Fragmentação de documentos, traduções persistentes, embeddings multilíngues, recuperação híbrida, RAG com citações, versionamento de conteúdo e políticas de retenção. Nesta versão apenas publicações são indexadas; comentários permanecem na tabela original.
