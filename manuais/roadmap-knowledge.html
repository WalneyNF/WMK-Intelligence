Python do básico ao avançado

Selecione Comunidades, clique Ver código Python e Executar. A função run recebe uma lista de dicionários com source, id, title, body, community e source_url. Counter agrupa e conta. Regex extrai URLs; SHA-256 identifica textos exatamente iguais após trim. A frequência de termos conta documentos, não ocorrências. Exercício: compare comunidades com a consulta SQL GROUP BY da biblioteca. Depois examine links e palavras. Não execute conteúdo encontrado nas fontes.

Scripts oficiais em scripts/data_lab; catálogo em config/data-lab.json. Somente IDs autorizados no código são executáveis. Não é sandbox: scripts oficiais rodam no processo servidor. Não instale scripts não confiáveis. A amostra tem até 5000 registros recentes, corpo limitado a 8000 caracteres e saída até 500 linhas. Duplicados são candidatos na amostra truncada.

Neural Notebook

Crie um caderno Python com termo python. Salve, selecione o caderno e consulte fontes sem IA. Compare com outro caderno RAG. Selecione Ollama ou Groq e pergunte quais técnicas aparecem. Groq exige consentimento. A busca LIKE recupera até 30 fontes recentes, das quais até 8 são enviadas à IA. Não é RAG semântico; não verifica alegações. Cadernos em dados/notebooks.sqlite3, sem histórico de conversas nesta versão.

v0.2 — Monaco e demonstrações

Execute instalar-monaco.bat na raiz (Node.js/npm e internet necessários uma vez). Reinicie o servidor e abra learning-lab.html. Monaco local 0.52.2; sem instalação permanece textarea. Carregue exemplos de config/learning-snippets.json. SQL executa o texto pelo validador somente leitura existente; Python oficial executa o arquivo original, não o texto editado. Exemplos Python e JS são para estudo e execução externa, não execução arbitrária no servidor.

Abra Dashboard API. Estude web/learning-demo.html, .css e .js: fetch, JSON, DOM, barras proporcionais e tratamento de erros. O endpoint /api/database/catalog fornece tabelas, contagens e até 20 comunidades. Sirva pelo servidor WMK; não abra via file://. API administrativa local, não exponha à internet. Para terceiros use a Open Knowledge API com autorização e chave.
