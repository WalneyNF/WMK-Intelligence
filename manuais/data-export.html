WMK Data Export Studio

Atualize o projeto, preserve dados e .env, reinicie e abra http://127.0.0.1:8767/export.html. Selecione conjunto, formato, fonte, limite e deslocamento. A memória é aberta mode=ro e query_only. Não exporta raw_json nem autor; textos ainda podem conter dados pessoais. Verifique direitos de reutilização.

API local

GET /api/export?dataset=posts&format=json&limit=1000&offset=0

Conjuntos posts, comments, assessments, memory. Formatos json, jsonl, csv, sql. Máximo 10000 registros e aproximadamente 16 milhões de caracteres por lote. Lotes independentes podem mudar durante coleta; pause coleta/indexação para consistência entre lotes. SQL específico SQLite; importe em banco separado. CSV neutraliza possíveis fórmulas, alterando essas células. JSON preserva texto. Não exponha endpoint administrativo na internet.

Python

import json, urllib.request
url = "http://127.0.0.1:8767/api/export?dataset=posts&format=json"
with urllib.request.urlopen(url) as r:
    posts = json.load(r)
print(len(posts))

JavaScript (mesma origem)

const r = await fetch('/api/export?dataset=posts&format=json');
if (!r.ok) throw Error('Falha');
console.log(await r.json());

PHP

<?php
$data = file_get_contents('http://127.0.0.1:8767/api/export?dataset=posts&format=json');
if ($data === false) exit('Falha');
$posts = json_decode($data, true, 512, JSON_THROW_ON_ERROR);
echo count($posts);

SQL

Abra um novo banco no DB Browser for SQLite e execute o arquivo SQL exportado. A tabela será wmk_export_posts ou equivalente. Não execute no banco original. Não há deduplicação automática na importação.
