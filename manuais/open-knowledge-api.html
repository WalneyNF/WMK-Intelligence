WMK Open Knowledge API v1

API REST JSON de leitura para aplicações externas. Serviço independente do coletor.

Instalação Windows

Gere uma chave com py -3 -c "import secrets; print(secrets.token_urlsafe(32))". Acrescente ao .env existente, sem apagar outras configurações:

WMK_OPEN_API_KEY=COLE_SUA_CHAVE_AQUI
WMK_OPEN_PORT=8768
WMK_OPEN_SOURCES=

Preencha WMK_OPEN_SOURCES com identificadores de fontes separados por vírgula somente após verificar autorização de redistribuição. Sem fontes autorizadas não são retornados registros. Execute na raiz:

py -3 -m wmk.public_api

Base: http://127.0.0.1:8768/api/open/v1. Todos os GET exigem Authorization: Bearer SUA_CHAVE.

Endpoints

GETParâmetros
/healthEstado do serviço
/sourcesFontes autorizadas e contagem
/statsTotal de registros e fontes
/postssource, page, limit (1–100)
/postsource, id; item null quando ausente
/searchq obrigatório, source, page, limit

Busca textual por termos no título e corpo (LIKE), não semântica. Resposta contém metadados e URL original, sem corpo, autor ou JSON bruto. Paginação por offset; novas coletas podem deslocar páginas.

JavaScript (Node.js 18+)

const r = await fetch('http://127.0.0.1:8768/api/open/v1/search?q=python', {
  headers: {Authorization: 'Bearer ' + process.env.WMK_OPEN_API_KEY}
});
if (!r.ok) throw new Error('HTTP ' + r.status);
console.log(await r.json());

Python (biblioteca padrão)

import os, json, urllib.request
url = 'http://127.0.0.1:8768/api/open/v1/search?q=python'
req = urllib.request.Request(url, headers={
    'Authorization': 'Bearer ' + os.environ['WMK_OPEN_API_KEY']})
with urllib.request.urlopen(req, timeout=10) as r:
    print(json.load(r))

PHP 8 com cURL

<?php
$c = curl_init('http://127.0.0.1:8768/api/open/v1/search?q=python');
curl_setopt_array($c, [
 CURLOPT_RETURNTRANSFER => true,
 CURLOPT_TIMEOUT => 10,
 CURLOPT_HTTPHEADER => ['Authorization: Bearer '.getenv('WMK_OPEN_API_KEY')]
]);
$body = curl_exec($c);
$status = curl_getinfo($c, CURLINFO_HTTP_CODE);
curl_close($c);
if ($status !== 200 || $body === false) throw new RuntimeException('Falha HTTP '.$status);
print_r(json_decode($body, true));

Celulares e aplicações web

O serviço escuta somente localhost. Para acesso remoto use um gateway HTTPS autenticado com limitação de requisições, controle de acesso e registros de auditoria. Nunca exponha a porta administrativa 8767. Não embuta a chave compartilhada em JavaScript de navegador ou aplicativo distribuído; use seu backend intermediário. CORS não está habilitado. Não exponha o servidor de desenvolvimento diretamente à internet.

Erros

400 parâmetros inválidos; 401 credencial ausente ou inválida; 404 rota inexistente; 405 escrita não permitida; 503 banco indisponível ou consulta demorada.

Governança

Informação pública não equivale a licença de redistribuição. Revise termos das fontes, direitos autorais, LGPD, retenção e exclusão. Títulos também podem conter dados pessoais; revise antes de habilitar uma fonte. MIT cobre o software, não os dados de terceiros.
