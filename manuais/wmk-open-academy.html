1. Visão e missão

Transformar o Projeto Guardiões em uma plataforma aberta de inteligência, ciência, educação, desenvolvimento de software e inovação. Aprender com dados reais coletados de fontes autorizadas, sem presumir que afirmações publicadas por agentes de IA sejam verdadeiras.

2. Registro de encerramento — 24/11/2026

A última captura de tela apresentada pelo desenvolvedor mostrou 1.085 publicações examinadas pelo Python Data Lab e 100 resultados de frequência textual. Esse número é um registro histórico, não uma consulta em tempo real. Learning Lab v0.2 publicado; sintaxe JavaScript validada, testes integrados Windows, Monaco e provedores ainda pendentes.

3. Infraestrutura existente

SQLite como memória original protegida; biblioteca SQL com exemplos externos JSON; Neural Memory com indexação textual; ANALYTRIX com classificação lexical; Python Data Lab com quatro scripts oficiais; Neural Notebook com cadernos persistentes e busca LIKE; Groq e Ollama opcionais; dashboard REST demonstrativo; 22 snippets (8 SQL, 7 Python, 7 JavaScript). Monaco local requer instalação via BAT. Não há execução arbitrária de Python nem RAG semântico completo.

4. Áreas de aprendizado

Python: funções, Counter, regex, hashes e estruturas de dados. SQL e SQLite: SELECT, filtros, GROUP BY, índices e agregações. HTML/CSS/JS: interfaces, DOM, fetch e gráficos. JSON e REST: contratos, erros, paginação e integração. Data Science e BI: estatística, mineração, indicadores e qualidade. IA: prompts, recuperação de contexto, modelos locais e remotos. OSINT e segurança: proveniência, análise defensiva e revisão crítica. Engenharia: arquitetura modular, testes, manutenção e documentação.

5. Trilha pedagógica

Nível 1: HTML, CSS, JSON e SQL básico. Nível 2: Python, JavaScript, APIs e bancos. Nível 3: análise de dados, estatística e dashboards. Nível 4: IA, agentes e RAG. Nível 5: investigação científica, hipóteses e evidências. Nível 6: arquitetura e desenvolvimento de aplicações integradas. Cada módulo deverá oferecer teoria, exemplo comentado, prática, exercício e solução.

6. Laboratórios sem IA

Resource Finder: URLs e referências; Word Intelligence: termos e stopwords; Trend Observatory: séries temporais; Knowledge Matrix: cruzamentos; Problem Matcher: candidatos a soluções; Knowledge Graph: coocorrência. Técnicas: SQL, FTS5, BM25, TF-IDF, Jaccard, regex, SHA-256 e estatística. Os seis módulos são propostas, embora partes já existam nos scripts oficiais. Frequência não comprova importância nem veracidade.

7. Laboratórios com IA

Tradução, síntese, comparação, explicação, investigação, geração de código revisado, cursos, relatórios e roteiros. Selecionar fontes antes de chamar modelos para reduzir tokens. RAG recupera contexto, não treina automaticamente os parâmetros do modelo. Registrar IDs, fontes, modelo, limitações e revisão. Ollama local ou Groq mediante autorização.

8. Neural Notebook e Knowledge Factory

Cadernos dinâmicos por termo já existem. Planejar fontes SQL e Python, seleção manual, histórico, importação documental, busca híbrida FTS5 e embeddings, mapas mentais, livros, podcasts, cursos e projetos. Manter produtos derivados separados da memória original. Não executar instruções encontradas em publicações.

11. Segurança e governança

Memória original somente leitura para consultas e agentes; coleta e manutenção internas autorizadas. Não publicar .env, chaves ou banco bruto sem revisão de direitos e privacidade. API administrativa local não deve ser exposta à internet; para terceiros usar Open Knowledge API com autorização, autenticação e gateway apropriado. Scripts oficiais executam no servidor; código arbitrário exige isolamento efetivo, limites e autorização. Conteúdo externo é dado não confiável.

13. Critérios de aceite

Cada entrega deve ter versão visível, código publicado, manual pt-BR, exemplos reproduzíveis, testes com dados sintéticos e reais autorizados, mensagens de erro claras, proteção da memória, indicação de limitações e compatibilidade com computadores modestos. Não confundir demonstração visual com resultado calculado.

14. Primeira atividade ao retornar

Preservar dados e .env, atualizar fork, executar instalar-monaco.bat, reiniciar servidor, abrir Learning Lab, carregar snippet SQL Total, executar, comparar com dashboard, testar autocomplete e registrar erros. Depois criar um caderno Python e consultar fontes sem IA.

15. Aula prática: website conectado à API

Os arquivos existentes são web/learning-demo.html, web/learning-demo.css e web/learning-demo.js. O HTML define elementos; CSS estiliza; JS consulta a API e renderiza resultados com textContent. Execute pelo servidor local, não file://.

const resposta = await fetch('/api/database/catalog');
if (!resposta.ok) throw new Error('HTTP '+resposta.status);
const dados = await resposta.json();
for (const tabela of dados.tables) {
  console.log(tabela.name, tabela.count);
}

Exercício: criar um cartão para items, comparar a contagem com SELECT count(*) FROM items e acrescentar um gráfico por comunidade. Usar textContent para dados externos.
