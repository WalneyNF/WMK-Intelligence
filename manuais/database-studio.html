Consultas

SELECT source, count(*) AS total FROM items GROUP BY source;
SELECT community, count(*) AS total FROM items GROUP BY community;
SELECT title, source_url FROM items WHERE lower(body) LIKE '%memory%' LIMIT 100;

Proteção

SQLite mode=ro, query_only e authorizer restritivo. Somente items, comments_v2, assessments_v2 e knowledge_memory. Até 200 linhas, prazo de processamento aproximado de três segundos. Não é uma API pública. Não disponibiliza arquivos arbitrários. Não inclui outros bancos derivados nem índice FTS.

Investigação

Pesquise problemas, compare fontes, verifique evidências, proponha ferramentas. Menções lexicais não comprovam soluções. IA assistente, gráficos e análise semântica são planejados. Testes de execução pendentes.

Editor avançado

Selecione campos do catálogo, use Ctrl+Enter, salve consultas no navegador, maximize a janela e exporte CSV ou JSON. O botão Abrir post requer source e id da publicação ou post_id. Tradução sob demanda em trechos de 3500 caracteres, com Ollama local ou Groq remoto. Groq recebe o título e trecho selecionado; não envie conteúdo cuja transferência não seja autorizada. Traduções podem conter erros e não alteram o original. O editor ainda é textarea, não Monaco.

v0.3 e v0.4

Monitores animados ambientais com contadores reais. Abra SQL livre, Montar consulta, selecione tabela e campo, gere SQL e execute. Gráfico aceita duas colunas categoria e valor não negativo. Enviar ao BI salva configuração no navegador. IA SQL envia pergunta e esquema ao provedor escolhido, retorna proposta sem executar. Revise antes de executar. O limite de 500 caracteres observado em um post ainda precisa de investigação.

Centro de operações v0.2

Acesse /operations.html. Novo monitor permite indicador, barras, linha, tabela e lista. Edite e exclua monitores personalizados. Arraste títulos para reorganizar e use a alça inferior para redimensionar. Exportação JSON inclui consultas e tipos dos monitores personalizados, não dimensões nem posições dos monitores padrão. Importação substitui os personalizados. Videowall oculta controles. Atualização a cada 30 segundos. Gráficos exibem até oito linhas. Testes completos pendentes.

v0.6 — Neural Insight

Abra uma publicação, escolha Ollama ou Groq, clique Consultar IA, selecione o modo e Analisar com IA. O modo pergunta personalizada aceita até 1500 caracteres. Groq exige confirmação de envio na interface. A análise usa até 12000 caracteres do corpo armazenado e não verifica fontes externas. Um corpo de 500 caracteres recebe aviso de possível truncamento. A memória original não é alterada.

Arraste janelas pelo cabeçalho, redimensione pela alça inferior, ajuste a divisão do leitor e maximize quando necessário. As janelas ainda são modais; layouts persistentes e monitores laterais móveis estão planejados.

API local POST /api/database/insight: JSON com source, id, provider, mode e question. Modos explain, technical, ideas, science, security, question. Retorna answer, provider, mode, characters, total, possibly_incomplete. Não exponha a porta administrativa.
